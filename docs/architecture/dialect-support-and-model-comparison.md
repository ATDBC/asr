# 本地模型与 Qwen 模型中文方言支持及特性对比

本文档记录本项目当前生产使用的**本地私有化 ASR 模型（FireRedASR2-AED）**与引入的**云端大模型（DashScope `qwen-audio-3.1-asr-flash-filetrans`）**在中文方言支持范围、转写输出行为与工程特性上的对比。

---

## 1. 核心横向对比

| 评测维度 | 本地模型 (FireRedASR2-AED) | 云端 Qwen 模型 (`qwen-audio-3.1-asr-flash-filetrans`) |
| :--- | :--- | :--- |
| **部署环境** | 物理 GPU0 私有化常驻运行，无外部依赖 | 阿里云 DashScope API 异步文件转写 |
| **语言与方言规模** | 中文（普通话 + **20+ 种**方言/口音）、英语 | **30 种**主流语言 + **16 种**中文代表性方言 |
| **方言检测方式** | 端到端声学模型直接泛化解码 | 单模型原生支持自动语种/方言识别，支持 `language_hints` |
| **转写文本风格** | 传统声学-语言模型解码，直译为规范书面汉字 | 依托 LLM 文本先验，直译并规范化为书面普通话汉字 |
| **标点预测行为** | 独立 BERT 标点模型（`FireRedPunc`），偏保守（逗号、句号为主） | 原生端到端标点预测，语气/疑问感知强（自然输出问号 `？`） |
| **词级时间戳** | 支持（AED cross-attention alignment） | 支持（API 原生返回 word-level begin/end_time） |

---

## 2. 本地模型：FireRedASR2-AED 方言支持

FireRedASR2-AED 是本项目的本地常驻转录引擎。其官方基于全国覆盖的 19 个公开方言基准（含 KeSpeech、WenetSpeech、MagicData 等）完成了系统性优化：

### 涵盖方言列表
- **粤语（Cantonese）**：香港粤语、广东日常交流、对话及车载场景（`ws-yue`、`md-yue`，CER 3%~8%）。
- **四川话 / 西南官话（Sichuanese）**：成都话、重庆话、日常与多轮会话（`ws-chuan`、`md-chuan`）。
- **上海话（Shanghai dialect）**：日常口语与对话（`md-shanghai`）。
- **吴语（Wu）**：江浙吴语区（`md-wu`）。
- **闽南语（Minnan）**：福建闽南地区方言及口音。
- **中原官话 / 河南话**：郑州话对话与日常（`md-zhengzhou`）。
- **湖北话**：武汉话（`md-wuhan`）。
- **天津话**：北方官话天津口音（`md-tianjin`）。
- **湖南话 / 湘语**：长沙话（`md-changsha`）。
- **其他省份方言与重口音**：安徽、福建、甘肃、贵州、河北、江西、辽宁（东北话）、宁夏、陕西、山西、山东、云南等（基于全国 34 个省级行政区基准 KeSpeech 调优，方言综合 CER 约 11.67%）。

## 3. 云端 Qwen 模型：Qwen-Audio 3.1 方言支持

Qwen-Audio-3.1-ASR 是阿里云百炼推出的端到端语音大模型。其文件转写版 `qwen-audio-3.1-asr-flash-filetrans` 针对中国 8 大方言区提供原生识别：

### 涵盖的 16 种代表性方言
1. **广东话（粤语 / Cantonese）**：广州话、香港话等。
2. **四川话 / 重庆话**：西南官话川渝区。
3. **上海话**：吴语核心区。
4. **浙江话 / 宁波话 / 温州话**：吴语浙南与浙东细分方言。
5. **闽南语**：福建、台湾闽南语系。
6. **客家话**：赣闽粤交界客家语。
7. **北方官话及各省主流方言**：
   - 东北话
   - 陕西话
   - 河南话
   - 河北话
   - 山东话 / 青岛话
   - 甘肃话
   - 宁夏话
   - 湖北话
   - 湖南话（湘语）
   - 江西话（赣语）
   - 贵州话 / 云南话（西南官话）

## 4. 实测效果案例（粤语测试音频：`粤语 1.m4a`）

使用 6.3 秒真实粤语对话音频进行端到端混合对齐验证（说话人分离固定使用 3D-Speaker + Nemotron-3）：

- **非 Qwen 混合版 (FireRedASR2-AED + FireRedPunc)**：
  ```text
  [00:00:01] 说话人1：你这句话是什么意思，你那句话是什么意思。
  ```
- **Qwen 混合版 (`qwen-audio-3.1-asr-flash-filetrans`)**：
  ```text
  [00:00:01] 说话人1：你这句话是什么意思？你那个话是什么意思？
  ```

### 实测观察
1. **内容理解**：两者均准确听懂粤语语义并规范化转换为现代汉语文字。
2. **细微词义**：前半句完全一致；后半句 FireRed 识别为“那句话”，Qwen 识别为“那个话”。
3. **标点语感**：Qwen 依托大语言模型底座，精准识别出疑问语调并赋予问号 `？`，更贴合自然交谈语境。

## 5. 特殊方言说明：温州话（瓯语）

温州话（南部吴语瓯江片）由于复杂的声韵调与连读变调系统，被公认为最难懂、最难识别的汉语方言之一。两款模型对其支持情况如下：

- **云端 Qwen 模型（重点专项支持）**：
  - 阿里通义千问团队在研发 Qwen-Audio 系列时，明确将“温州话”作为攻克中国难懂方言的重点标杆，将其单独列入官方支持的 16 种代表性方言（细分支持了浙南温州话与浙东宁波话）。
  - 在底层音频 Tokenizer 和端到端语音建模中对温州话声调轨迹与音系特征进行了针对性训练，原生具备温州话转写能力。
- **本地模型 FireRedASR2-AED（泛化覆盖，无专项调优）**：
  - FireRed 官方声明支持“吴语（Wu）”与“上海话”，但其训练与公开评测基准主要基于北部吴语/太湖片（苏沪嘉一带的 `md-wu` 数据集）。
  - 由于温州话属于南部吴语（瓯江片），与北部吴语互通度极低且音系差异显著，FireRed 未对纯正温州方言做独立基准调优。它能较好泛化处理带有温州口音的普通话（温普），但对地道、生涩的纯温州方言识别难度较大。

**业务选型建议**：若录音为地道纯正的**温州话**，推荐采用 **Qwen 混合对齐方案**。

### 温州话实测案例（温州市鹿城区民间故事《吃粥选女婿》前 45 秒）

- **真值对照（方言字 / 普通话意译）**：
  > 溫州民間故事，喫粥選女兒婿。早年能界（以前的時候），楠溪江有一個員外屋裏（家裏），有一個女兒生好顯生好（長得很好看）。渠想選女兒婿。消息一傳啊開，驚動爻多顯多個後生兒（年輕人）。渠徠全部走來託媒相親。講親。有徠屋裏極有鈔票（很有錢），有徠屋裏做官個，有徠屋裏讀書極有出息。該員外個眼珠吶就眙眙花啦爻（眼睛都看花了），決定弗落（決定不下來）。祇好女兒自出主意。

- **云端 Qwen 混合版 (`qwen-audio-3.1-asr-flash-filetrans`)**：
  ```text
  [00:00:03] 说话人1：温州民间故事，喝酒选女婿。早年的时候，楠溪江有一个员外家里，有一个女儿长得非常好看，他喜欢女儿玩，玩着玩着，惊动了许许多多的小孩子，他们全部过来偷看，说亲，有的家里很有钱，有的家里做官的，有的家里读书很有出息，这个员外的眼睛呢，都看花了。
  [00:00:39] 说话人1：激动不了，只好让女儿自己出主意。
  ```

- **本地混合版 (FireRedASR2-AED + FireRedPunc)**：
  ```text
  [00:00:03] 说话人1：一九梦噶故事，此九虚囊塞。
  [00:00:08] 说话人1：昨日那个男主角要一个女娃娃嘞。有一个让学习结合。给嘘嘘那样噻。Thisisjackie.讲多我读书读妖仙。给了。你不咋嘞？偷卖西餐。国仓？要来屋里才有钞票，要来屋里做鬼，要来屋里到世界上去睡。这女娲这样子呢，又只吃胡萝。
  [00:00:39] 说话人1：自动俘虏之后还能失去记忆，女娲。
  ```

**实测对比结论**：
1. **Qwen 成功实现温州话语义到标准普通话的准确转写**：“温州民间故事”、“早年的时候”、“楠溪江有一个员外家里”、“女儿长得非常好看”、“有的家里很有钱，有的家里做官的，有的家里读书很有出息”、“这个员外的眼睛呢，都看花了”、“只好让女儿自己出主意”，几乎完全切中温州话的实际含义。
2. **本地 FireRed 完全无法理解纯正温州方言**：由于缺乏南部吴语（瓯江片）的数据训练，本地模型严重失真，将温州话完全听成了荒谬的乱码、幻觉词（如“Thisisjackie”、“偷卖西餐”、“要来屋里做鬼”、“女娲”等）。
3. **充分实证了前述判断**：面对温州话等重度复杂方言，云端 Qwen 的专项方言建模具有压倒性优势。
